Ten doodles drawn entirely by code

No image model, no API key, no network at render time. Scenes compile from a small JSON scene language through rough.js plus real handwriting fonts; charts come from matplotlib's xkcd sketch mode. Every image below has an editable SVG beside it, and the same seed always redraws the identical wobble.
