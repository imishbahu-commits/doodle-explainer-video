# Narrative Structure & Pacing

*Source: [ai-video-editing-skill](https://github.com/znyupup/ai-video-editing-skill) + professional editing craft*

## Three-Act Structure

### Act 1 — Setup (~25%)
- **Purpose**: Hook the viewer, establish context, build anticipation
- **Pacing**: Medium-fast, 2-3 second shots
- **Content**: Best visual moments as montage hook → context establishment → promise of what's coming
- **Music**: Energy building, lighter instrumentation
- **Hook rule**: The first 3 seconds determine if the viewer stays. Lead with your strongest visual.

### Act 2 — Development (~50%)
- **Purpose**: Main content, escalating interest, deepening engagement
- **Pacing**: Varied, 3-5 second average with fast/slow alternation
- **Content**: Organized by theme/location/activity, each sub-section with its own mini-arc
- **Music**: Full instrumentation, energy matching content peaks and valleys
- **Tension curve**: Gradually escalate — each segment should be slightly more interesting than the last

### Act 3 — Resolution (~25%)
- **Purpose**: Climax + emotional payoff + satisfying closure
- **Pacing**: Slow build → peak moment → breathing room → final beat
- **Content**: Best/most emotional moment → reflection → closing image/message
- **Music**: Peak energy at climax → gradual wind-down → final note
- **Ending types**: Callback to opening, full circle, lingering beauty shot, humor button, fade to black

## Shot Rhythm

### The Golden Rhythm: 3-4 Seconds
This is the average. Vary around it constantly:

```
Pattern: 3s - 2s - 4s - 1.5s - 5s - 2s - 3s - 8s - 2s - 3s
         ↑ normal  ↑ quick ↑ hold  ↑ breath  ↑ montage  ↑ long hold
```

### Rhythm by Mood
| Mood | Average Shot Length | Pattern |
|------|-------------------|---------|
| Energetic | 1.5-2.5s | Fast-fast-hold-fast-fast |
| Calm | 4-8s | Hold-slow-hold-long |
| Tense | 2-4s, accelerating | Medium-medium-short-shorter-cut! |
| Joyful | 2-4s, varied | Medium-quick-hold-quick-medium |
| Epic | 3-6s | Build-build-long hold-quick burst |

### Pacing Traps
- **Monotonous rhythm** = death. If every shot is 3s, the viewer zones out.
- **All fast cuts** = exhausting. No time to process emotion.
- **All long holds** = boring. Viewer's mind wanders.
- **No breathing room** = overwhelming. Give 1-2 beats of calm after intense sections.

## Content Architecture for Different Formats

### Vlog (3-10 min)
8-15 segments, each 2-7 clips. Three-act structure. Content mix: action 30-40%, scenery 30%, people 15%, b-roll 15%.

### Tutorial/How-To (5-20 min)
Hook → Problem statement → Steps (with visual demonstrations) → Result → Recap. Pacing: medium, with pauses for comprehension.

### Product Demo (30s-3 min)
Problem (5s) → Solution intro (5s) → Features/benefits (main) → Social proof (brief) → CTA (5s).

### Social/Short-Form (<60s)
Hook (1-2s) → One key message → Visual evidence → Ending punch. No slow buildup — every second counts.

### Documentary (10+ min)
Context → Characters → Tension → Investigation → Revelation → Resolution → Reflection. Longer holds, more breathing room, interview-driven pacing.
