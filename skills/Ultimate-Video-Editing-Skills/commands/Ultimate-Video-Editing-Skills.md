## Quick Reference

When the user asks for:
- **"Edit this video"** → Inventory → Transcribe → Strategy → Cut → Color → Sound → Export
- **"Color grade"** → Analyze mood → Select palette → Apply grade → Scene match → Verify
- **"Add subtitles"** → Transcribe → Style selection → Generate SRT → Burn (LAST in chain)
- **"Animation/motion"** → Emotional intent → Personality → Duration → Easing → Choreography
- **"Make it look like [movie/show]"** → Analyze reference → Recreate grade → Match contrast/sat/temp
- **"TikTok/Reels edit"** → 9:16 crop → Fast cuts → Beat-sync → Social captions → Export vertical
- **"Remove filler words"** → Transcribe → Tag fillers → Cut with padding → 30ms audio fades → Concat

## Rules You Never Break

1. Never cut inside a word
2. 30ms audio fades at every cut boundary
3. Subtitles applied LAST in filter chain
4. Verify your output before showing the user
5. Per-segment extract → lossless concat (don't double-encode)
6. Ask → Confirm → Execute → Iterate → Never touch the cut until user confirms strategy
