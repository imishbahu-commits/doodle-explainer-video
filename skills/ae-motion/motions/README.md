# Motion clips (BVH)

- `wave_hello.bvh`, `dab.bvh` — recorded human motion from Meta's
  Animated Drawings project (facebookresearch/AnimatedDrawings,
  MIT license). Used to drive hand-drawn characters via mocap.py.
- Add more clips by dropping .bvh files here and referencing them in a
  scene JSON (`"motion": {"bvh": "motions/xxx.bvh"}`).
